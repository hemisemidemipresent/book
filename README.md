# book

idk a book about ordinals and big numbers

```sh
typst watch main.typ main.pdf
```

If you really want light mode, change the `theme: "dark"`, though some trees in chapter 6 have hardcoded color values.

Parts labelled `WIP` are work in progress. Sometimes they are just incomplete, and somethings they are more like a call for help cause idk whats going on.

Editorial Notes
